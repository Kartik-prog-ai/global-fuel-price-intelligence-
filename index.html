About the Project

This project analyzes global fuel prices and taxation trends from 2020 to 2026. It compares petrol, diesel, and LPG prices across countries and explores variations in taxation, subsidies, income groups, and Brent crude oil prices.

Global Fuel Price and Taxation Analysis

This project uses data visualization to explore differences in fuel prices between countries and examine how fuel taxation and subsidy levels vary across regions.

  • Dataset: Global Fuel Prices
  • Coverage: 84 countries
  • Period: 2020–2026
  • Fuel Types: Petrol, Diesel, LPG
  • Records: 27,468 rows
  • Fields: 10 variables
  • Tools: Tableau, Flask
  • Analysis: Interactive visuals

The dashboard includes country-level comparisons, global price-distribution maps, fuel-price trends, and taxation analysis. The Story presents the main findings in a clear sequence. Results describe patterns in this dataset and do not prove causation.

Project Summary

Global Fuel Price Analytics

A data analytics project focused on comparing global fuel prices and exploring taxation, subsidy, and crude-oil price trends using Tableau visualizations.

  • Dataset: Global Fuel Prices
  • Time period: 2020–2026
  • Tools: Tableau Public, HTML, CSS, JavaScript, Flask

Dataset Details

Global Fuel Prices Dataset

2020–2026

84 countries across multiple regions and income levels

The dataset contains date, country, region, income level, subsidy level, petrol price, diesel price, LPG price, Brent crude price, and tax percentage.

Fuel and Tax Indicators
